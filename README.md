# Angel Morenu Portfolio

Personal portfolio for Angel Morenu, an applied data scientist focused on biomedical AI, bioinformatics, healthcare analytics, and reliable data workflows.

## Preview locally

From the repository root:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000/` or the corresponding local repository path in a browser.

## Site structure

- `index.html` contains the profile-style page structure and professional content.
- `styles.css` contains the responsive visual system and mobile layout.
- `script.js` renders the featured project cards.
- `docs/` contains downloadable resumes, CVs, and project reports.
- `images/` contains portfolio imagery.

The site is a static GitHub Pages site and does not require a build step.
